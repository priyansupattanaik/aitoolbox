# AI ToolBox

A curated collection of the most powerful AI tools, organized by category.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite 5 + SWC
- **Routing**: React Router DOM v6
- **Styling**: Tailwind CSS 3
- **Icons**: lucide-react

## Getting Started

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Preview

```sh
npm run preview
```
