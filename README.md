# AI ToolBox

[AI ToolBox](https://aitoolsbox.netlify.app) is a directory of AI tools. Open it when you want one place to look up a tool for writing, images, code, or audio, see what that tool is for, and go to its site.

## What it does

Each entry shows the tool’s name, a short description, and a link to that tool’s own page. The directory groups them into four categories:

- **Text** — tools that generate, rewrite, or check text
- **Image** — tools that create and enhance images
- **Coding** — assistants for writing and running code
- **Audio** — tools for speech and music

Search by name or description, or show a single category. Choosing a tool opens that product on its own site.

## What it is for

AI ToolBox is for finding the right kind of AI product without visiting each site first. It points you to the tool. The work itself happens there.

A description on an entry is a label in the directory. It is not a review, a price, or a promise that the link still opens.
